# 系统监控功能快速指南

## 问题背景

客户需要了解CentOS 7服务器空闲时的CPU和内存使用情况，以便为灾备系统采购提供参考。传统的`top`命令需要手动计算，不够直观。

## 解决方案

本项目提供了专门的监控模块，可以直接获取CPU和内存使用率，无需手动计算。

## 快速使用（3步）

### 第1步：检查工具

```bash
source ./lib/loader.sh
check_monitor_tools
```

如果提示缺少工具，安装：
```bash
yum install -y bc sysstat
```

### 第2步：生成灾备采购报告（推荐）

这是最简单直接的方式，会自动监控并生成包含采购建议的完整报告：

```bash
source ./lib/loader.sh

# 监控30次，每次间隔10秒（约5分钟）
generate_backup_report 30 10
```

报告会自动保存到 `~/.LOG/ProjectManage.sh_LOG/` 目录。

### 第3步：查看报告

报告文件会显示：
- 系统基本信息（CPU型号、核心数、总内存）
- 空闲时资源使用统计（平均值、最大值、最小值）
- **灾备系统配置建议**（CPU、内存配置建议）

## 其他常用功能

## 推荐监控方案

### 方案1：快速评估（约1分钟）
```bash
source ./lib/loader.sh
monitor_system_resources 12 5  # 监控12次，每次5秒
```

### 方案2：标准评估（约5分钟，推荐）
```bash
source ./lib/loader.sh
generate_backup_report 30 10  # 监控30次，每次10秒，生成采购报告
```

### 方案3：详细评估（约10分钟）
```bash
source ./lib/loader.sh
generate_backup_report 60 10  # 监控60次，每次10秒
```

## 注意事项

1. **监控时机**：建议在系统相对空闲时进行监控，以获得准确的空闲时使用情况
2. **监控时长**：至少监控5分钟（30次×10秒）才能获得较准确的统计数据
3. **多台服务器**：在每台服务器上分别运行，然后对比报告
4. **业务高峰期**：除了空闲时监控，也建议在业务高峰期监控，综合评估

## 常见问题

**Q: 报告保存在哪里？**  
A: `~/.LOG/ProjectManage.sh_LOG/backup_system_report_YYYYMMDD_HHMMSS.txt`

**Q: 可以同时监控多台服务器吗？**  
A: 可以，在每台服务器上分别运行监控脚本即可。

**Q: 监控会影响系统性能吗？**  
A: 影响很小，建议监控间隔至少5秒。
